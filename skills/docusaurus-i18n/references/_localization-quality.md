# Web Copy Localization Quality

Core principle: **Localize, don't translate.**

Translated web pages must read as if a native speaker wrote the copy from scratch for their local audience.

## Web Copy Categories

Different content types have different rules:

| Type | Rule | Example |
|------|------|---------|
| Hero headline | Short, punchy, benefit-first | "Get more done. Stress less." |
| Feature heading | Scannable, 3-6 words | "Track time, not tasks" |
| Feature description | Natural sentence, benefit-oriented | "Drag tasks around. Done ones disappear." |
| CTA button | Action verb, 2-4 words | "Start free", "Try it now" |
| FAQ question | Natural phrasing, not robotic | "How does pricing work?" |
| FAQ answer | Conversational, not manual-like | "You pay per seat, billed monthly." |
| Meta description | SEO-aware, locally natural | Include local search terms |

## Per-Language Guidelines

### Japanese (ja)
- Casual tone for consumer web — avoid keigo
- Noun-ending sentences are natural (体言止め)
- Remove colons — unnatural in Japanese (`"通知時間"` not `"通知時間:"`)
- Avoid passive voice (`"カレンダーを表示"` not `"カレンダーが表示されます"`)
- Reduce ~性 suffix overuse (`"信頼できる安定した動作"` not `"信頼性の高い可用性"`)
- **Bad:** "タスクを効率的に管理することができるツールです" (verbose, translated feel)
- **Good:** "タスクをサクッと管理" (natural, casual)
- **Bad:** "包括的なタスク管理ソリューション" (AI翻訳臭)
- **Good:** "やることを、まとめて管理" (native phrasing)

### Korean (ko)
- Casual/friendly register (-해요 or noun endings)
- Avoid formal -습니다 for consumer web
- 할 일 (casual) over 작업 (formal/technical)
- **Bad:** "작업을 효율적으로 관리할 수 있습니다" (overly formal, translated)
- **Good:** "할 일, 한눈에 정리" (casual, scannable)
- **Bad:** "포괄적인 일정 관리 솔루션" (AI翻訳)
- **Good:** "일정 관리, 이걸로 끝" (native, punchy)

### Chinese Simplified (zh-Hans)
- Short punchy phrases preferred
- Four-character idioms (成语) add rhythm when appropriate
- Avoid written/formal register (书面语)
- **Bad:** "全面的任务管理解决方案" (formal, translated feel)
- **Good:** "轻松搞定每日待办" (conversational, benefit-first)
- **Bad:** "请使用我们的服务来管理您的时间" (overly polite, verbose)
- **Good:** "时间管理，就这么简单" (direct, native)

### German (de)
- "du" form for consumer web (dein/deine, not Ihr/Ihre)
- Direct and concise — avoid unnecessary compound nouns
- Address user directly
- **Bad:** "Eine umfassende Aufgabenverwaltungslösung" (compound noun monster)
- **Good:** "Deine Aufgaben, gut sortiert" (direct, casual)
- **Bad:** "Verwalten Sie Ihre Aufgaben effizient" (Sie form, corporate)
- **Good:** "Erledige mehr, stresse weniger" (du-implied, benefit-first)

### Spanish (es)
- Tu form for consumer web (avoid usted)
- Warm but concise
- **Bad:** "Una solución integral para la gestión de tareas" (corporate, verbose)
- **Good:** "Organiza tus tareas a tu manera" (casual, direct)
- **Bad:** "Por favor, siéntase libre de probar nuestro servicio" (keigo leak)
- **Good:** "Pruébalo gratis" (direct CTA)

### French (fr)
- Tu form for consumer web (ton/ta, not votre)
- Slightly more formal than EN, but not stiff
- Avoid anglicisms where French equivalents exist
- **Bad:** "Une solution complète de gestion de tâches" (formal, generic)
- **Good:** "Tes tâches, bien organisées" (casual, direct)
- **Bad:** "N'hésitez pas à essayer notre service" (vous, overly polite)
- **Good:** "Essaie gratuitement" (tu form, direct CTA)

### Other Languages
- Apply the same "localize, don't translate" principle
- Use informal/casual register for consumer web
- Research local web copy conventions before translating
- When in doubt, prioritize naturalness over literal accuracy

## Common Anti-patterns (All Languages)

1. **AI vocabulary leaking into translations** — "包括的", "効率的な", "ソリューション" in JA; similar in other languages
2. **Source-language word order** — Rearrange to feel native, don't map 1:1
3. **Literal idiom translation** — Use local equivalents
4. **Inconsistent register** — If hero is casual, all sections should be casual
5. **Over-translating** — Keep brand names (Chimr, Vigilare) and tech terms (API, MCP) untranslated
6. **Formal register in casual web copy** — Match the app's consumer tone per locale
