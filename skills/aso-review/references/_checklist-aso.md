# ASO Review Checklist

Per-locale review checklist. Every item MUST be evaluated for EACH detected locale independently.

## Keywords

- [ ] Keywords are locally researched, NOT translated from source language
- [ ] High-volume search terms for the local market are included
- [ ] Keywords reflect how local users actually search (colloquial terms)
- [ ] No keyword stuffing (natural reading flow preserved)
- [ ] Competitor keywords analyzed per market (competitors differ by region)

## Subtitle (30-char limit)

- [ ] Within character limit (CJK: ~15 chars, Latin: ~30 chars, RTL: varies)
- [ ] Contains primary keyword for the locale
- [ ] Reads as a natural phrase, not a keyword list
- [ ] Communicates core benefit, not feature list

## Description

- [ ] First 3 lines convey the main value proposition (above the fold)
- [ ] Opens with benefit, not feature list
- [ ] Feature descriptions use local terminology
- [ ] Call-to-action matches local conventions
- [ ] No literal translation of source-language idioms

## Value Proposition

- [ ] Core value proposition is consistent across locales
- [ ] Benefit framing adapted to local market expectations
- [ ] Competitive differentiation reflects local competitors
- [ ] Price/currency format correct for locale

## Cross-Locale Consistency

- [ ] Feature names are consistent across all locales
- [ ] Brand terms are handled consistently (translated vs kept original)
- [ ] Screenshots referenced in description match locale
- [ ] No contradicting claims between locales
